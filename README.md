# taikyokuclock-legal

iOS アプリ **対局時計（Game Clock）** の法務・サポートページ。GitHub Pages で公開している。

- 日本語: https://seishin1114-source.github.io/taikyokuclock-legal/
- English: https://seishin1114-source.github.io/taikyokuclock-legal/en/

内容の原本は本体リポジトリの `AppStore/legal/` にある。**編集はそちらで行い、
`AppStore/legal/publish.sh` を実行して反映する**（このリポジトリを直接編集しない）。
